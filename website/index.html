DNS Shunt
View source ↗

A local Windows utility

Precise DNS overrides. No resolver changes.

DNS Shunt lets you direct selected domain names to chosen IP addresses, right on your Windows computer. The rest of your DNS traffic carries on as usual.

Get the latest release ↗ Windows 10/11 x64
One rule, one detour
MATCHING NAME dev.example.test → chosen IP address
EVERYTHING ELSE Other DNS requests → Windows-selected resolver

No adapter DNS changes. No resolver selection.

01 / MATCH

Overrides, on your terms.

Add an exact domain or a wildcard for its subdomains, then set the IP address it should resolve to. Only matching A/IN queries for IPv4 addresses receive a synthesized answer.

02 / PASS THROUGH

Your DNS stays yours.

Unmatched and unsupported requests pass through unchanged. Windows continues to choose the resolver; DNS Shunt does not change adapter settings or configure a resolver.

03 / RUN

Enabled when you decide.

Manual packet capture is opt-in. Install the Windows service explicitly to use service mode. Capture is limited to outbound, non-loopback IPv4 DNS over UDP port 53.
